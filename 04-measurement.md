# 04 · Measurement — how anything is declared done

- **yardstick** *(ES: vara)* — A declared local test standard. Two yardsticks are never mixed; every figure declares which one it came from.
- **gates n=2 / double green** — A measurement passes twice, in separate runs, before it travels. One green pass travels nowhere.
- **red before green** — A guardian must first fail against the defect it hunts. A test that has never seen red proves nothing.
- **sabotage** *(ES: sabotaje)* — A deliberate mutation the test MUST detect. Demanded with its count: "sabotages 6/6 detected". A 0/6 is a red gate and is declared, never hidden.
- **the Guardian** *(ES: el guardián)* — The test that turns a law into an executable rule. D1, privacy, ceilings: "build me the Guardian of X" — the law stops depending on memory.
- **determinism** — Same input → same frame; measured by hashing the canvas bitmap. Seven sections = exactly seven distinct hashes, stable across reloads and directions.
- **stamps in receipts** — Every measured claim carries its stamp; SIMULATED fixtures are declared as such and never dressed as measured.
- **measured close** *(ES: cierre con la medida)* — A close carries the figure beside it. "RESOLVED" without a number is a second opinion.
- **incidence honesty** — A red run inside a green series stays in the record with its cause (even when the harness discarded the detail: internal cause NO_DATA). A bounce is never hidden behind a success.
