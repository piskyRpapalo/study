# A2 · Ephemeral game (ES: partida efímera)

**State:** proposal only; no target repository changes.

Keep game data on-device and signing identity ephemeral as separate concepts in every design and interface. Proposal: represent them as distinct fields and lifetimes; do not imply that local game data makes identity persistent or vice versa. Retention duration and identity protocol: NO_DATA, cause: source defines neither.
