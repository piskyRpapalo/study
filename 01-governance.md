# 01 · Governance and method — who decides, who measures, who signs

- **the Sovereign** *(ES: el Soberano)* — The carbon; the only signer. Every decision is surfaced to him one at a time, without pressure. Silicon never signs.
- **the Command Desk (the Desk)** *(ES: la Mesa de Mando)* — Measures, triages, proposes; never decides for the Sovereign; surfaces one decision at a time.
- **sign-off** *(ES: FIRMO)* — The Sovereign's decision made visible. Authorizes exactly what it names; a general sign-off never covers future, unmeasured merges.
- **seal** *(ES: sello)* — A short letter-code assigned only by the Desk; travels in the merge commit. Not a signature.
- **round** *(ES: ronda)* — One sealed exchange, numbered, append-only. Cited by number; never renumbered.
- **the Ledger** *(ES: el registro de rondas)* — The append-only round log. Rules over measured facts when sources conflict.
- **the Register** *(ES: el registro del rack)* — The Sovereign's cryptographic record in the rack; entries signed with a rotating key. NOT the Ledger.
- **entry** *(ES: entrada)* — One numbered record in the Register (e.g. Entry 24).
- **ruling** *(ES: dirimencia)* — A resolved issue that fixes doctrine (e.g. #40: no HLC this phase; #42: score finite-or-null, EPSILON declared). The first source of duplicates is re-proposing what a ruling already fixed.
- **commission** *(ES: encargo)* — A paste-ready work order with its law in the body: new context, what is asked, the fences (what is NOT touched), and the yardstick.
- **receipt** *(ES: recibo)* — The return message: form only — numbers, dates, shapes. Never keys, never private names.
- **propose-only** *(ES: proponer sin ejecutar)* — Silicon writes and proposes; it never merges, never signs, never pushes.
- **the Comando** *(ES: el Comando)* — The single GitHub lane: the issues-repo where commissions and receipts land; mirror of what the app hosts in its own database. One channel, so no preceptor guesses where anything lives.
- **Customs** *(ES: la aduana)* — The gate where a PR waits for the Desk's measurement before any sign-off. The deployed Worker verifies signed credentials and writes only hashes.
- **the lanes** — the Arm (web-coder lane: writes, measures, receipts) · the Descent (the game's visual language) · the Codex lane / astra (the app side, tier-2). Lanes never sign.
- **preceptor** — Any AI that reads this world and works under these laws.
- **the Signing Tray · measured close** *(ES: bandeja de firmas · cierre con la medida)* — The rack's pending table; a row closes with the measure beside it. "RESOLVED" without a number is a second opinion.
