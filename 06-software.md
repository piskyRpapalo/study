# 06 · Software — the stack

- **Three public lanes + the rack** — PreceptorOS = the app (local-first companion: local memory, local inference, zero cloud); preceptoros-web = the web (public gateway and game, nine languages, zero external requests on load); lab = the benchmarks; p0x = the private rack monorepo (the loops, the doctrine); study = the public doctrine.
- **local-first doctrine** — The app runs on your machine; the site is only the door. No cloud calls, no external requests at load, local inference via local models.
- **PWA / service worker** — The web installs as an app with an offline shell in nine languages; caches are named by VERSION — whoever merges last re-seals.
- **the bubble language** — The game's visual language: every scene drawn as syllables (799–1,014 B each) under param_gate; determinism verified by bitmap hash.
- **vector contract (W2)** — comic_atoms ↔ geometry: colors are the tokens of the atlas plus accents; new layers add geometry and light, never new colors.
- **harmonic draw** *(ES: gacha armónica)* — The wave-shaped draw engine; odds shown before the gesture.
- **the Eye's stack** — Served work is looked at before polishing: loopback port 8807 in the rack + the phone via scrcpy over adb reverse (loopback only, never a public network).
- **test stack** — Python unittest suites + the `bin/pruebas` runner (1,026 tests, 71 suites, sabotage runners per suite) + remote CI matrix (Python 3.10–3.14).
- **Customs Worker** — Cloudflare Worker + D1: verifies signed charters with the Sovereign's public key, writes only hashes. Never signs. Deployment pending a separate sign-off.
- **local brains** — The rack's local model catalog, served over an internal bridge; the public network is never used. Benchmarked with its own yardstick.
